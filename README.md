## Highlights

- **Loader and entrance.** A percentage counter, then a curtain that slides up while the headline letters rise one by one.
- **Headline that reacts to you.** Letters near the cursor lift up and change color.
- **Parallax hero images.** Three floating demo screens that drift with the pointer.
- **Scrolling marquee** with solid and outlined type.
- **Project cards.** Images wipe in as you scroll, then tilt in 3D on hover.
- **Counters and skill bars** that animate when they come into view.
- **Custom cursor and magnetic buttons** on desktop (mouse devices only).
- **Scroll progress bar** in the navigation.
- **Light and dark theme.** Follows the system setting, with a toggle that remembers the choice.
- **Mobile menu** with a full-screen slide-down overlay.
- **Demo images included.** Every picture is an SVG generated by the script, so there are no image files to manage.

## Quick start

1. Download or clone the repository.
2. Make sure the file is named `index.html`.
3. Double-click it, or serve it locally:

```bash
git clone https://github.com/<your-username>/sahan-studio.git
cd sahan-studio
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Make it yours

Everything lives in `index.html`. These are the places you will edit most.

### 1. Colors and theme

Colors are CSS variables at the top of the `<style>` block. Change the light values in `:root`, and the dark values in the two dark blocks.

```css
:root{
  --bg:#eef0f6;   /* page background */
  --tx:#0a1033;   /* main text */
  --ac:#2a3bff;   /* main accent */
  --ac2:#ffd23f;  /* second accent */
}
```

### 2. Your name and text

Search the file for `Sahan Perera` and `sahan.studio`, then replace them with your own name, logo text and email. The headline, intro text, stats, skills and work history are plain HTML, so edit them directly.

### 3. Projects

Projects come from one array in the script. Add, remove or edit entries:

```js
const W = [
  ['Project name', 'Year', 'Short description.', ['Tag one', 'Tag two']],
];
```

### 4. Images

Project pictures are generated by the `art(i)` function using the colors in the `P` array. To use real screenshots, replace `src="${art(i)}"` in the project template with the path to your own image, for example `src="images/lumen.jpg"`.

### 5. Contact form

The form is a demo and does not send anything. To receive messages, point it at a form service such as Formspree or Netlify Forms, or connect your own backend.

## Deploy on GitHub Pages

1. Push `index.html` to the `main` branch.
2. Open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. After a minute, your site is live at `https://<your-username>.github.io/sahan-studio/`.

## Quality notes

- Responsive from small phones to wide desktops.
- Respects the `prefers-reduced-motion` setting by shortening animations.
- Visible keyboard focus and labelled form fields and buttons.
- Handles phone notches and system bars with safe-area padding.
- Works without any build tools or packages.

Current versions of Chrome, Edge, Firefox and Safari. Older browsers may not show the `color-mix()` hover effects.
